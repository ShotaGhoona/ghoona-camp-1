### 3. 高機能管理スクリプト

#### 3.1 migrate.sh（マイグレーション管理）
**主要機能:**
- `up`: 全マイグレーション順次実行
- `status`: 適用状況確認（カラー表示）
- `seed [environment]`: 環境別シードデータ投入
- `reset`: データベース完全リセット

**特徴:**
- 重複実行防止（schema_migrations管理）
- カラフルなログ表示
- エラーハンドリング完備
- 実行前接続確認

#### 3.2 db-setup.sh（環境別セットアップ）
**主要機能:**
- 環境指定完全セットアップ
- `--reset`: リセット付きセットアップ
- `--migrations-only`: マイグレーションのみ
- `--seeds-only`: シードデータのみ

**使用例:**
```bash
# 開発環境完全セットアップ
./db/scripts/db-setup.sh development

# テスト環境リセット付き
./db/scripts/db-setup.sh testing --reset

# 本番環境セットアップ
./db/scripts/db-setup.sh production
```

### 4. 古いシステムの完全削除

#### 4.1 削除対象
- `backend/internal/infrastructure/database/migrations/` (GORMベース)
- `backend/cmd/migrate/` (古いGoコマンド)
- `backend/cmd/seed/` (未実装シードコマンド)
- `backend/scripts/check_db.go` (重複機能)
- `backend/scripts/setup_tables.go` (重複機能)

#### 4.2 削除理由
- 機能重複・保守負担
- 未実装・動作不可能なコード
- 新システムで完全代替済み
